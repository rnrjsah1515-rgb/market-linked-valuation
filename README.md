## 2. 이 프로젝트가 답하려 한 것

항공사 이익은 유가와 환율에 크게 좌우되는데, 영업이익률을 과거 평균으로 두는 일반적인 DCF는
"유가가 20% 오르면 가치가 얼마나 줄어드는가"에 답하지 못합니다. 그래서 원가를 분해해 시장 변수가 들어갈 자리를 만들었습니다.

```
매출     = 기준매출 × 물량성장 × (1 + 달러매출비중 × 환율변화) + 유류할증 전가분
유류비   = 유류 소비량 × 유가(달러/배럴) × 환율(원/달러)
비유류비 = 비유류비율 × 기준매출 × 물량성장
FCFF    = EBIT × (1−t) + 감가상각비 − CAPEX − 운전자본 증감
주주가치 = EV − 순차입금 − 환율 재평가(달러 순부채) − 비지배지분
```

유가·환율이 기업가치로 전달되는 경로를 먼저 정의하고, 무엇을 넣고 뺄지 명시했습니다.

| 경로 | 내용 | 반영 |
|---|---|---|
| A | 유류비 증가 | 반영 |
| B | 유류할증료로 일부 매출 전가 | 반영 (전가율 50% 가정) |
| C | 운임 상승에 따른 수요 감소 | **제외** (6장) |
| D·E | 달러 매출·비용의 원화 환산 | 반영 (민감도 분석에서 사용) |
| F | 달러 순부채의 원화 환산액 변동 | 반영 (공시 순외화부채 35억달러) |

## 4. 판단이 필요했던 지점

이 프로젝트에서 결과를 좌우한 것은 코드가 아니라 아래 네 가지 판단이었습니다.

### (1) 기준연도 — 아시아나 연결로 손익과 재무상태표의 범위가 달랐다

대한항공은 2024년 12월 31일을 인수의제일로 아시아나를 연결했습니다. 그래서 2024년 재무상태표에는
아시아나가 전액 들어 있지만 손익계산서에는 들어 있지 않습니다. 순차입금 17.2조를 대한항공 단독 이익과
비교하게 되는 문제가 생깁니다.

**→ 손익·투자 항목에 아시아나 연결 실적을 더해 pro forma로 맞췄습니다.**

| 2024년 | 공시 | + 아시아나 | = pro forma |
|---|---|---|---|
| 매출 | 178,707억 | 83,186억 | **261,893억** |
| 영업이익 | 21,102억 | 2,757억 | 23,859억 |
| 감가상각비 | 17,960억 | 11,525억 | 29,485억 |
| 유류비 | 49,808억 | 25,567억 | 75,376억 |
| CAPEX | 29,063억 | 7,155억 | 36,218억 |

대한항공이 주석 46에 공시한 pro forma 매출(26,189,286백만원)과 **정확히 일치**합니다. 리스부채도
58,534 + 50,732 = 109,266억으로 맞아떨어져, 합산 범위가 맞는지 두 번 검증했습니다.

### (2) 비율 기간 — 화물 호황기를 평균에 넣을 것인가

2022~2023년은 코로나 화물 호황으로 비유류비/매출이 39~48%였고, 2024년은 50.9%입니다.
3년 평균(46.1%)을 쓰면 가치가 2.5배로 뜁니다. **손익과 재무상태표 범위가 일치하는 2024년만 사용**했습니다.
역산 결과 시장이 함축하는 비율(51.3%)이 2024년 실적과 거의 같다는 점도 이 선택을 뒷받침합니다.

### (3) 할인율 — 주가회귀 베타로는 추정이 안 됐다

| 방법 | 베타 | WACC |
|---|---|---|
| KOSPI 대비 회귀 | 0.517 | 4.33% |
| KOSPI 반도체 제외 대비 회귀 | 0.620 (R² 18%) | 4.47% |
| **회사 공시 (채택)** | — | **8.40%** |

평가기준일 현재 반도체 3종목이 KOSPI 시가총액의 25.5%를 차지해 개별 종목 베타가 왜곡됩니다.
반도체를 제외한 지수로 다시 추정해도 설명력(R²)이 18%에 그쳤습니다. 목표 자본구조를 바꿔도 WACC는
4.33%→4.38%로 거의 변하지 않았는데, 베타를 목표 구조로 재레버리지하면 자본구조 효과가 상쇄되기 때문입니다(MM 명제).

**→ 대한항공이 2024년 사업보고서 주석 46에서 아시아나 고객관련무형자산을 평가할 때 사용한
가중평균자본비용 8.4%를 채택**했습니다. 출처가 분명하고 같은 산업·같은 시점의 값입니다.

### (4) 자본구조

리스부채를 부채에 포함하면 부채 비중이 71%가 됩니다. 채택 할인율이 공시값이므로 자본구조 가정은
결과에 직접 영향을 주지 않으며, CAPM 계산값은 참고로만 병기했습니다.

## 6. 과거 시점 검증 (backtest)

각 사업보고서 공시 직후 시점에서, **그때 공시된 자료만으로** 모델을 돌렸다면 주가와 얼마나 달랐는지 확인했습니다.
할인율은 8.4%로 고정했습니다. 실행은 [`backtest.py`](backtest.py), 결과는 [`output/backtest.csv`](output/backtest.csv)에 있습니다.

|---|---|---|---|---|---|---|---|

### 왜 달랐는가

**1. 기준연도 실적을 영구화하기 때문입니다.** 모델은 기준연도의 마진·비용구조가 계속된다고 가정합니다.
그래서 실적이 바닥인 해(2020년 코로나)에는 가치가 음수로, 정점인 해(2022년 화물 호황)에는 시장의 3배로 나왔습니다.

**2. 시장은 정반대로 움직였습니다.** 시장 EV/EBITDA는 실적이 바닥일 때 11.6배, 정점일 때 4.2배였습니다.
경기민감 산업에서 시장은 이익이 낮을 때 높은 배수를, 이익이 높을 때 낮은 배수를 적용해 **평균 회귀를 가격에 반영**합니다.
모델은 그 반대로 외삽합니다. 괴리의 대부분은 이 차이에서 나옵니다.

**3. 실적이 정상 범위일 때는 ±20% 안에 들어옵니다.** 2023·2024년처럼 EBITDA 마진이 20~22%로 안정된 해를 기준으로 하면
괴리가 +22%, +19%로 줄었습니다. 모델 자체의 구조적 오류라기보다 **기준연도 선택의 문제**입니다.

**4. 주가 예측력은 없습니다.** 모델이 저평가라고 본 뒤 1년 주가는 5회 중 2회만 같은 방향이었습니다
(2021-03 저평가 판정 후 +11%, 2023-03 저평가 판정 후 −6.5%). 표본이 5개뿐이라 통계적 의미도 없습니다.

### 정상화(normalization)를 넣으면 나아지는가

기준연도 실적을 그대로 쓰는 대신 세 가지 정상화 방식을 같은 틀에서 비교했습니다.
사이클 평균은 확보 가능한 과거 연도(2019년~기준연도)의 평균 비유류비율입니다.

| 평가일 | 실제 주가 | ① 기준연도 그대로 | ② 사이클 평균 마진 | ③ 마진 수렴(3년) | ④ 매출+마진 정상화 |
|---|---|---|---|---|---|
| 2021-03-31 | 27,200원 | −245% | −246% | −246% | −245% |
| 2022-03-31 | 30,200원 | −65% | −145% | −141% | −141% |
| 2023-03-31 | 23,200원 | **+202%** | **−23%** | **−12%** | −72% |
| 2024-03-31 | 21,700원 | +22% | +1% | +2% | −39% |
| 2025-03-31 | 21,300원 | +19% | +141% | +135% | +8% |
| **평균 절대 괴리** | | **111%** | **111%** | **107%** | **101%** |

**결과: 기계적인 정상화 규칙으로는 평균 오차가 거의 줄지 않습니다.**

- 실적이 정점인 해(2022년 화물 호황)에는 정상화가 결정적으로 효과적입니다. +202% → −12%.
- 반대로 2025-03 시점에서는 사이클 평균이 오히려 오차를 키웁니다(+19% → +141%). 평균에 호황기(2022~2023년)와
  아시아나 연결 전 범위가 섞여 있어, 그 평균이 "정상"이 아니기 때문입니다.
- 2021-03 시점은 어떤 방식으로도 고쳐지지 않습니다(−245%). 코로나로 매출이 반토막 난 상태에서 순차입금이 11조였고,
  **"여객 수요가 회복된다"는 판단 없이는 어떤 규칙도 음수를 벗어나지 못합니다.** 그 판단을 한 쪽이 시장이었습니다.

### 시기별 시장위험(할인율)을 역산하면 설명되는가

괴리의 원인이 "시기마다 다른 시장위험을 할인율 8.4% 하나로 고정한 탓"인지 확인했습니다.
각 시점의 주가를 그대로 설명하는 할인율을 역산하고, 관측 가능한 위험지표와 비교했습니다.

![implied risk](output/charts/implied_risk.png)

| 평가일 | 무위험이자율 | 신용스프레드 | 재레버리지 베타 | **내재 할인율**(마진수렴) | 내재 자기자본비용 | 내재 시장위험프리미엄 |
|---|---|---|---|---|---|---|
| 2021-03-31 | 2.1% | 0.0%p | 1.165 | **2.2%** | 2.2% | 0.1% |
| 2022-03-31 | 3.0% | 0.4%p | 0.891 | **4.0%** | 5.0% | 2.2% |
| 2023-03-31 | 3.3% | 0.7%p | 0.972 | **8.0%** | 13.6% | 10.6% |
| 2024-03-31 | 3.4% | 0.5%p | 0.906 | **8.5%** | 15.1% | 12.9% |
| 2025-03-31 | 2.8% | 0.4%p | 0.745 | **10.9%** | 30.3% | 36.9% |

**결론: 시장위험으로 설명되지 않습니다.**

- 관측된 위험지표(무위험이자율 + 신용스프레드)는 2.1% → 3.2% 범위에서 거의 움직이지 않았는데,
  내재 할인율은 2.2% → 10.9%로 5배 벌어졌습니다. 방향도 무위험이자율과 반대입니다(2025년은 금리가 내렸는데 내재 할인율은 최고).
- 역산한 시장위험프리미엄은 0.1% → 36.9%입니다. **어떤 시장에서도 성립하지 않는 값**이라, 이 수치는 위험이 아니라
  다른 오차를 떠안은 조정항(plug)으로 봐야 합니다.
- 2021-03 시점은 내재 할인율이 2.2%인데, 이는 영구성장률(2.0%)과 거의 같은 값입니다. 즉 **할인율을 아무리 낮춰도
  그 시점 예상 현금흐름으로는 주가를 설명할 수 없다**는 뜻입니다. 시장은 할인율이 아니라 **회복된 이익**을 보고 있었습니다.
- 다만 실적이 정상 범위였던 2023·2024년 기준 시점의 내재 할인율은 8.0%, 8.5%로, 채택한 8.4%와 거의 같습니다.
  **정상 국면에서는 8%대라는 할인율 선택이 타당했음**을 사후적으로 확인해 줍니다.

### 이 검증에서 얻은 것

- 이 모델은 **가격 예측 도구가 아니라 "가정 → 가치" 변환 도구**입니다. 절대값보다 "어떤 가정이면 얼마"를 보는 데 씁니다.
- 기준연도가 비정상이면 결과 전체가 무의미해집니다. **정상화가 DCF의 핵심 판단**임을 수치로 확인했습니다.
- 그리고 그 정상화는 **규칙이 아니라 판단**입니다. "무엇이 정상인가"를 정하는 순간 결과가 결정되며,
  평균·수렴 같은 기계적 대안은 특정 국면에서만 통했습니다. 이 프로젝트가 채택한 "2024년만 사용"도 같은 성격의 판단이고,
  그 판단이 맞는지는 시장가격 역산(5장)으로 교차 확인했습니다.

## 7. 한계와 확인할 점

- **잔존가치가 EV의 83%**입니다. 할인율 1%포인트 변화에 가치가 크게 움직이며, EV/EBITDA 배수법을 교차검증으로 병기했습니다.
- **내부거래 미제거**: pro forma 합산에서 두 회사 간 코드셰어 등 내부거래를 공개 자료로 제거할 수 없어 매출·비용이 소폭 과대될 수 있습니다.
- **주식 종류**: 보통주 상장주식수 기준이며 우선주·자기주식·신종자본증권은 조정하지 않았습니다.
- **항공유 스프레드**: 벤치마크 원유 대비 항공유 프리미엄을 일정하다고 가정합니다(2025년 기준 약 1.38배).
- **유류할증 전가율 50%**는 근거가 약한 가정입니다. 실제 전가 구조는 거리 구간별 단계제입니다.
- **DART 계정 매핑**은 계정명 패턴에 의존합니다. 엑셀 `DART_매핑로그` 시트에서 확인해야 하며, 실제로 이 과정에서
  2021~2023년 CAPEX가 "유형자산 및 투자부동산의 취득"으로 표기돼 누락된 오류를 발견해 수정했습니다.

### 검토했으나 반영하지 않은 경로: 유류할증료 인상에 따른 수요 감소

| 항목 | 내용 |
|---|---|
| 검토 방법 | 인천공항 국제선 출발 여객(유임승객 − 환승객)을 목적지 거리별로 나눠, 할증료 급등기(2026년 5~6월 발권분 33·27단계)와 평상시(2019 vs 2018, 2025 vs 2024)의 전년 대비 증가율 격차를 비교 |
| 데이터 | 공공데이터포털 `인천국제공항공사_항공사별 노선별 운송실적`, 공항 좌표(OurAirports), 유류할증료 단계(항공사 공지·보도) |
| 결과 | 중거리(동남아) 노선에서 평소 범위를 벗어난 추가 감소(6~9%p)가 관찰됐으나 두 달에 불과. 장거리는 같은 시기 전쟁 영향과 분리 불가. 평상시에는 할증료 변동폭이 작아(장거리 편도 수만~10만 원대) 탄력성 추정 불가 |
| 판단 | 근거가 부족해 DCF 에서 제외. 물량 성장률은 유가와 독립적으로 설정 |
| 영향 방향 | 유가 상승 시 비용 증가에 수요 감소가 겹칠 수 있어 **유가 상승 시나리오의 가치 하락이 과소평가될 수 있음** |

## 8. NH선물 API 연동 계획

현재 유가·환율 커브는 "최근 12개월 평균 고정"이라는 임시 가정입니다.
[`src/market.py`](src/market.py)의 `NHFuturesCurve`가 연동 자리입니다.

| 단계 | 내용 | 가치평가에서의 의미 |
|---|---|---|
| 1 | 해외 원유 선물 월물 → 회계연도별 평균 선도가격 | 유가 가정을 "과거 평균"에서 "시장이 합의한 가격"으로 교체 |
| 2 | 미국달러선물 월물 → 연도별 선도환율 | 환율 가정의 시장 근거 |
| 3 | 헤지 전략을 계약 수로 환산, 증거금·롤오버 비용 반영 | 헤지 비용을 포함한 순효과 |
| 4 | 옵션 내재변동성으로 몬테카를로 변동성 교체 | 과거 변동성 대신 시장 기대 |

참고로 대한항공은 연간 예상 소모량의 최대 50% 이내에서 Zero Cost Collar 등으로 헤지한다고 공시하고 있어,
모델의 헤지 비율 분석(0~75%)과 직접 비교할 수 있습니다.

## 9. 실행 방법

```bash
pip install -r requirements.txt
cp .env.example .env        # DART, ECOS, 공공데이터포털 키 입력
python run.py               # → output/
python backtest.py          # 과거 시점 검증 → output/backtest.csv
python run.py --demo        # API 키 없이 가상 데이터로 흐름 확인
python -m unittest discover -s tests -t .
```

Windows 에 Excel 이 있으면 실행 마지막에 엑셀 모델을 재계산해 파이썬 결과와 일치하는지 자동 확인합니다.

```

│  ├─ financials.py     DART 계정 → 표준 항목 매핑, pro forma 합산, 매핑 로그

│  ├─ model.py          WACC, 유가·환율 연동 추정, DCF, 달러 순부채 환율 재평가

│  ├─ risk.py           민감도, 몬테카를로, 헤지 분석
│  └─ report.py         차트, 엑셀 모델, 요약
├─ tests/               계정 매핑·DCF·시뮬레이션·환율 재평가 테스트
└─ output/              summary.md, valuation_model.xlsx, charts/
```
